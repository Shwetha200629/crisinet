# CrisisNet — Hospitality Emergency Response System

AI-powered real-time crisis management for hotels using Python Flask + Google Gemini AI.

## Hackathon
Challenge: [Rapid Crisis Response] Accelerated Emergency Response and Crisis Coordination in Hospitality

## Run Locally
pip install -r requirements.txt
python app.py
Open: http://localhost:5000
